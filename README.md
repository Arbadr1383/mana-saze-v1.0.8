# MANA SAZEH — HTML/PWA starter

این بسته یک رابط کاربری واقعی HTML/CSS/JavaScript برای مدیریت پروژه‌های ساختمانی دارد. فایل شروع: `frontend/index.html`.

## دیدن سریع رابط
1. پوشه را استخراج کنید.
2. برای تست ساده وارد `frontend` شوید و `index.html` را در مرورگر باز کنید. نصب PWA و Service Worker به `localhost` یا HTTPS نیاز دارد.
3. برای اجرای محلی PWA در PowerShell داخل پوشه `frontend` اجرا کنید: `python -m http.server 8080` سپس `http://localhost:8080` را باز کنید.

## نکته مهم
این نسخه فعلاً نمونه اولیه رابط است و فرم‌ها داده را در LocalStorage همان مرورگر ذخیره می‌کنند. هنوز به API جاوا یا PostgreSQL وصل نشده و برای چندکاربره/داده واقعی آماده نیست. برای نصب PWA، `localhost` یا HTTPS لازم است. تاریخ شمسی فعلاً در فرم به صورت متن وارد می‌شود و تقویم انتخاب‌گر کامل هنوز اضافه نشده است.

اعتبار سازنده: علیرضا بدر — شرکت برنامه‌نویسی قو (SwanCo).


## مدیریت کاربران (نسخه نمایشی)
در منوی «مدیریت کاربران» برای ایجاد کاربر، تأیید حساب سازنده لازم است. حساب سازنده با نام کاربری `ali` و رمز `1383` در فهرست کاربران نمایش داده نمی‌شود. این بررسی فعلاً فقط سمت مرورگر است؛ چون فایل JavaScript قابل مشاهده و ویرایش است، این روش حساب مخفی امن ایجاد نمی‌کند. رمزهای کاربران در LocalStorage ذخیره نمی‌شوند و حساب‌های ساخته‌شده هنوز ورود واقعی ندارند. برای نسخه عملیاتی، تأیید سازنده، هش رمز عبور، ورود کاربران و مجوزها باید در بک‌اند Java/Spring Boot و PostgreSQL پیاده‌سازی شوند؛ همچنین توصیه می‌شود رمز سازنده پیش از انتشار عمومی تغییر کند.


## صفحه ورود — نسخه 1.0.2
- پس از انیمیشن آغازین MANA، صفحه ورود نمایش داده می‌شود.
- حساب سازنده برای ورود: نام کاربری `ali` و رمز `1383`.
- کاربران ساخته‌شده در ماژول مدیریت کاربران نیز می‌توانند با نام کاربری و رمز تعریف‌شده وارد شوند.
- دکمه خروج به صفحه ورود برمی‌گرداند.
- در نسخه فعلی، اعتبارسنجی ورود و نگهداری داده‌ها سمت مرورگر است و جایگزین احراز هویت امن سمت سرور نیست. هش محلی رمزها نیز برای امنیت عملیاتی کافی نیست. برای انتشار واقعی باید ورود، نشست، مجوزها و تأیید سازنده در Java/Spring Boot پیاده‌سازی شود.
- کاربران قدیمی نسخه 1.0.1 که فقط `passwordConfigured` دارند، رمز قابل ورود ذخیره‌شده ندارند؛ آن حساب‌ها را از فهرست حذف و پس از این نسخه دوباره ایجاد کنید.

- دکمه ویرایش قرارداد فقط برای کاربری با نقش «مدیر پروژه» نمایش داده می‌شود؛ مدیر پروژه می‌تواند خریدار، پروژه/واحد، نوع و شماره قرارداد، مبلغ‌ها، تاریخ و تعداد اقساط را ویرایش کند.
